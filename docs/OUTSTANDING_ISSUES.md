- Frozen-video detection uses a short sample. Deliberately static channels may be false positives; the result is conservative and is cached for a day.
- EPG retry policy: `fetch_epg` now retries 3x, rejects truncated gzip bodies, and falls back to the last complete cached body (README "EPG resilience"). Re-enabling a flaky guide no longer risks silent coverage loss, but retries do not fix a source that yields nothing — yield probes still gate every addition.

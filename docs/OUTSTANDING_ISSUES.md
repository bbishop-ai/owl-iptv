Re-enabling a flaky guide no longer risks silent coverage loss, but retries do not fix a source that yields nothing — yield probes still gate every addition.
- Local-affiliate streams bundled from Vizio/amagi feeds publish a bare network tvg-id (`CBS.us`/`Fox.us`/`NBC.us`) while the only yielding schedule family for them, epgshare01 `US_LOCALS1`, keys channels by station call sign (`KBZK-DT.us_locals1`). Bridged by the generic rule `pipeline.apply_affiliate_callsign_aliases`: it parses the call sign out of each published row's own display name (big-four brand prefix + `[KW][A-Z]{3}` token), injects `<CALL>`/`<CALL>-DT` as alt-names before matching, and lets the existing matcher enforce per-guide uniqueness plus its region guard. Rule projection over the current live playlist applies to exactly 8 rows and excludes Fox Weather sub-brands. Because the upstream station set churns between builds (KCPQ primary→backup, KOAA/KDFW→absent within one day), the rule replaces an earlier per-station config table. Trade-off accepted 2026-11-26: joining by true station id splits previously merged network tiles into per-station tiles in players that group by `tvg-id`; two same-network rows cannot both show their own market's schedule under one shared id, so this is the honest direction.
- Station web-encoder mirrors (foxdigital/Vizio affiliates, Townnews `g-mana`, field59, uplynk station channels) are affiliate *streaming* feeds whose lineups legally exclude live national sports windows — proven frame-by-frame on Thanksgiving 2026 when every one of them aired local programming through both CBS and Fox NFL kickoffs while `FOX Sports on Tubi` (Tubi id 613683, now integrated via source `f30873f60166`) simultaneously streamed live NASCAR coverage of the same window. Transport-level probes passed all day; content was never football. Consequence: NFL-on-CBS/Fox/NBC national games cannot be carried from this source class at all — rights-held origins only. Tubi exposes its games separately from the linear catalog, as per-event content pages with rotating stream ids (verified 2026-11-26: live-page `contentIdsByContainer` contained exactly the 175 static FAST ids and zero event ids); automating that lane means an event-driven resolver with key-rot + prune handling per `references/grey-stream-source-research.md` — NOT built yet. Until then, live-game carriage inside this pipeline should be treated as impossible rather than flaky, and any "verified playing" claim must be backed by a decoded frame, not a manifest check.
- Source-integration filter trap (earned 2026-11-26, two builds): BuddyChewChew's Tubi playlist EXTINF rows carry no `tvg-language`/country, so after normalization they are `unknown`/empty and BOTH strict pre-preselect filters (`filter.languages=[en]` with `allow_unknown:false`, plus US-prefer) drop all 172 rows BEFORE the validation budget stage — which is why #16's `priority_tvg_ids` lane changed nothing (it runs downstream of the filters; stats stayed byte-identical between the two builds). The repo lever for exactly this shape is the per-source `"force_us_english": true` flag (same as the english-sports-extras bundle), applied here via PR #17. Lesson order-of-operations for future source adds: check upstream attribute completeness FIRST against the filter chain, then the budget — a zero-publish build with byte-identical counters to its predecessor means the rows died in an early deterministic filter, not in contention.

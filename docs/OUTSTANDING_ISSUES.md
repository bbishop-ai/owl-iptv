- All five Gitee `taksssss/tv` EPG guides (`4963d1f5313f` 112114/CCTV, `d6c2fdb5ddda` epgpw_tw, `ef54d905e093` epgpw_cn, `7d6e019e5b6b` 51zmt, `31d3fa32a2fb` epgpw_hk) were disabled 2026-10-04. Evidence: the China-hosted raw server truncates mid-download from US runners intermittently (each guide failed at least once across recent runs), and combined measured yield for the whole family against the live playlist was at most 17 raw joins out of 1,422 entries (~1%), all sub-priority to rank 0-4 guides and all foreign-language. Re-enable only against `unmatched_channels.json` with meaningful incremental joins.
- Production channel counts are network- and region-dependent. The 500-stream sanity floor is intentionally below the verified baseline and may need adjustment if upstream coverage changes materially.
- LAN multicast and live FOFA/ZoomEye discovery from walke2019 are inventoried but cannot run meaningfully or safely from a shared GitHub-hosted runner.
- Frozen-video detection uses a short sample. Deliberately static channels may be false positives; the result is conservative and is cached for a day.
- EPG retry policy: `fetch_epg` now retries 3x, rejects truncated gzip bodies, and falls back to the last complete cached body (README "EPG resilience"). Re-enabling a flaky guide no longer risks silent coverage loss, but retries do not fix a source that yields nothing — yield probes still gate every addition.
- Local-affiliate streams bundled from Vizio/amagi feeds publish a bare network tvg-id (`CBS.us`/`Fox.us`/`NBC.us`) while the only yielding schedule family for them, epgshare01 `US_LOCALS1`, keys channels by station call sign (`KBZK-DT.us_locals1`). Bridged by the generic rule `pipeline.apply_affiliate_callsign_aliases`: it parses the call sign out of each published row's own display name (big-four brand prefix + `[KW][A-Z]{3}` token), injects `<CALL>`/`<CALL>-DT` as alt-names before matching, and lets the existing matcher enforce per-guide uniqueness plus its region guard. Rule projection over the current live playlist applies to exactly 8 rows and excludes Fox Weather sub-brands. Because the upstream station set churns between builds (KCPQ primary→backup, KOAA/KDFW→absent within one day), the rule replaces an earlier per-station config table. Trade-off accepted 2026-11-26: joining by true station id splits previously merged network tiles into per-station tiles in players that group by `tvg-id`; two same-network rows cannot both show their own market's schedule under one shared id, so this is the honest direction.
